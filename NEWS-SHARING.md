# Shared lab news

The personal website loads `https://hexd-lab.github.io/news-feed.json`, generated by Jekyll from `_news/` during each lab-site deployment.

Add `personal_site: true` to an announcement's YAML front matter to include it on the personal website. Set it to `false` or omit it to show it only on the lab site. All existing announcements and templates currently include this flag. Files under `_news/templates/` are always excluded from the feed.

Keep writing announcements in the lab repository; no matching personal-site file is needed. Dates determine display order. For `inline: false`, the personal site links to the full lab post.

Merge and deploy this feed before merging the personal site's consumer PR.
